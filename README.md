Команди, що були використані у ході роботи :
git init - для створення локального репозиторію

git branch -M main - щоб перейменувати гілку, у якій я знаходжуся, бо по замовчуванню основна гілка називається master. При виконанні git push  в віддаленому репозиторію створювалась нова гілка, тож було прийняте рішення змінити назву у локальному для уникнення такої ситуації

git status - показує змінені, видалені або нові файли (лише ті, що не були закомічені) в локальному репозиторію 

git add . - для додавання змісту файлу до системи відстеження git 

git commit -m "..." - для того, аби зробити коміт

git push/ git push --set-upstream origin main - для того, щоб у віддалений репозиторій додалось те, що було у локальному 

git pull/git pull origin main - щоб у локальний репозиторій додалось те, що було у віддаленому
